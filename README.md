## 安装与使用

1. 从 GitHub Releases 下载 macos-arm64.dmg，打开并将应用拖入 Applications。
2. 当前发布包只有本地 ad-hoc 签名，没有 Apple Developer ID 签名或公证。Gatekeeper 可能阻止打开；仅在确认来源和 SHA-256 后，按 macOS 官方“隐私与安全性”中的单应用允许打开流程处理。不要关闭系统安全保护。
3. 接入模块，装好天线和支持短信、数据业务的 SIM 卡，保持稳定 USB 供电；只接一台受支持模块。
4. 如果设备状态提示未发现配套固件，点击“安装／修复固件”，核对模块丝印后输入 Air780EHV 确认。首次须通过 Wi-Fi 等现有网络下载官方核心与烧录工具并进行 SHA-256 校验；不能指望尚未配置的模块自己下载固件。
5. 烧录会覆盖设备原有核心与 Lua 脚本、重启并短暂断网；本软件不备份原固件。未同步短信可能丢失。不要拔线，保存烧录日志；没有烧录按钮的已验证设备可通过软件进入下载模式。
6. 点击“启动上网”启用 USB ECM；点击“停止上网”关闭模块 USB 上网功能。这不会停止 Mac 的 Wi-Fi、有线网或 VPN。
7. 等状态显示“短信就绪”，填写收件人号码、短信内容，点击发送并确认费用。已发送列表显示提交结果；失败有详情，未知结果不可直接认定失败后重复发送。
8. 收件箱支持刷新、查看、删除和恢复。后台约每 15 秒同步；删除是 Mac 列表软删除，不是清除 SIM 存储。
   0.9 新增“已删除”页的“清空”：确认后永久删除该列表全部短信（包括未显示的记录），不可恢复，不影响收件箱、已发送或设备上网。仅保留不含正文和号码的消息 ID 防止模块缓存重新同步；不是 SIM 清理或磁盘安全擦除。
   0.9.1 修正：USB 信息下方依据 macOS 中匹配 USB 网卡的 AirM2M Compo 系统网络服务显示状态，每 5 秒刷新。系统服务停用时显示“已停用／已停止上网”；启用但链路或 IP 未就绪时显示“已激活／未连接”；只有系统服务启用、网卡 UP、链路 active 和有效地址才显示“已启动上网（互联网未验证）”。模块 ECM 开关单独显示，不代表系统服务或 SIM 账户已激活。应用不会擅自撤销用户的系统停用操作；在系统中停用的服务需由用户重新启用。
9. 顶部以五格图标显示最新同步的信号。收件箱每行“已接收”后可点击“回复短信”自动填入号码；发送失败记录后可点击“重新发送”，核对确认框后重发，保留原失败记录。不确定结果不提供一键重发，以免重复计费。
10. 点击“邮件转发设置”，填写一个 SMTP 发件账户、发件邮箱及最多三个收件邮箱，选择 SSL（常见端口 465）或 STARTTLS（常见端口 587），输入邮箱密码或 SMTP 授权码并启用。密码存入 macOS 钥匙串；留空保留原值。可点“保存并测试 SMTP”检查加密登录，不发送测试邮件。必须自行使用邮箱服务商提供的正确设置。
11. 转发只覆盖启用设置后新同步的短信，应用须保持打开且 Mac 联网。不自动转发历史短信，也不在后台常驻运行；详情和失败结果可通过邮件设置里的“查看转发记录”查询。转发包含发送号码、时间及正文，可能包含验证码等敏感内容，请确认邮箱属于可信接收方。
12. AirM2M 服务停用时点击状态后面的“激活网卡”，软件只启用匹配的 USB 系统网络服务并复查结果；权限不足时提供打开系统网络设置，手工启用 AirM2M Compo。始终可直接点“打开网络设置”。系统网卡激活不等于模块 ECM 或互联网已可用，必要时再点击启动上网。
13. 应用菜单提供“关于”和“复制脱敏诊断信息”。同一个应用只运行一个实例，避免重复同步抢占串口。

## 五格信号与邮件转发

LTE RSRP 使用近似五格分级：≥ -85 dBm 为 5 格；-95 至 -86 为 4 格；-105 至 -96 为 3 格；-115 至 -106 为 2 格；更低的有效值为 1 格。无效或未读取到的值显示“信号未知”，不是满格。该分级不是运营商标准，鼠标悬停可查看原始 RSRP；后台约每 15 秒刷新。

邮件只使用验证服务器证书的加密连接，密码通过匿名管道传递给后端，不放进命令行或配置文件。普通配置和转发记录保存在本地数据目录。邮件服务器接受不等于收件箱最终收到；提交中连接中断或进程退出时记录为结果未知，不自动重复发送。连接/登录失败尚未提交内容，可在下一轮安全重试。正式运行前须自行测试邮箱配置与真实接收。

连接失败按 1–15 分钟间隔退避重试；SMTP 认证失败时暂停自动登录，需修正账户或授权码后重新保存设置。更新应用后 macOS 可能再次询问钥匙串访问权限。一个 SMTP 发件账户可将短信分别转发到最多三个接收邮箱。

## 验证范围与限制

- 原有硬件版已验证 Air780EHV_A11 ECM 绑定接口上网，以及一条中文测试短信的运营商提交成功。
- 本公开版的独立打包与通用端口发现已通过自动测试和离线后端自检；0.8 邮件转发经模拟 SMTP 测试，未使用真实邮箱发送。安装前请了解验证范围，不能视为全面实测。
- “发送成功”表示模块/运营商接口接受提交，不等于对方手机已经收到；目前不提供送达回执。
- 真实入站短信、跨运营商和长短信仍需用户验证。模块 RAM 缓存最多约 100 条；应用关闭时收到的未同步短信，重启后可能丢失。
- 1–500 字符普通中文、英文、标点；不支持 emoji 等非 BMP 字符。长短信可能按多条计费。需要 SIM 和运营商开通相关业务；物联网卡可能只允许上网。
- SIM 手机号不一定写入 SIM，可显示为空或未知；不能从 IMSI/ICCID 推算号码。
- 软件启用 ECM 并检查模块接口联网，但不修改系统全局默认路由、DNS 或 VPN。现有 VPN 可能仍接管流量。自定义 APN、PIN 解锁、Intel Mac、多设备并发未支持。
- 没有自动升级或遥测；邮箱转发默认关闭，启用后会把新短信发送到用户指定邮箱。首次烧录下载会连接官方固件 CDN 和 GitHub；联网检测会访问网络检测服务。

## 数据与隐私

数据位于 ~/Library/Application Support/Air780E Modem/，包括本地 SQLite 短信记录、设备操作锁和下载缓存；不包含在发布包里。
短信数据库未做应用层加密，请保护 Mac 账户并开启 FileVault。
提交 Issue 时请遮盖手机号、短信内容、IMSI、ICCID、IMEI 和本机用户名；勿上传整个数据目录。

## 开发和构建

需要 Apple Silicon Mac、macOS 26+、Xcode Command Line Tools、Python 3.11 或更新版本（本次构建使用 Python 3.14.6）。旧系统构建需要选择兼容运行库并单独验证，不能只修改 Info.plist 声称兼容。

```sh
python3 -m unittest discover -s src -p 'test_*.py'
bash scripts/build_macos.sh
bash scripts/package_release.sh
```

源码入口 src/backend_entry.py，UI 在 src/ModemApp.swift，设备脚本在 firmware/lua/main.lua。
开发者命令示例：python3 src/backend_entry.py status。不要在不了解费用与后果时运行 send_sms 或 install_firmware。
构建不自动访问 USB、烧录或发送短信。dist/<版本号>/ 中生成 app ZIP、DMG、源码 ZIP 和 SHA256SUMS.txt，并自动审计源码包。
