## English

- Maker footer now includes **DJ Network (点击网络) · Stock code: 832571**, with www.DJ.cn, Cai Liwen and cailiwen@dj.cn retained.
- Top-right language selector: **Simplified Chinese (first-launch default), English, Traditional Chinese**. The choice persists; switching preserves recipient, draft and folder. Buttons, state labels, menus, SMS/delete confirmations and SMTP settings are localized. Raw vendor logs, SMS, numbers and protocol data remain unchanged.
- Includes the 0.9.4 card-based UI and 0.9.5 per-row Sent deletion, select-all and bottom batch deletion. Confirmation is required; active sends are protected. Deletion removes Mac history only, never recalls SMS.
- English README plus bilingual maintenance/security/privacy/troubleshooting/protocol/verification/license notices and historical release/update documentation. Historical 0.9.3 release notes gain English; its original binaries are unchanged.

**Apple Silicon/macOS 26+/Air780EHV_A11 (EC718HM) only.** Independent community software, ad-hoc signed, **not Developer ID signed or Apple notarized**. No phone-call feature. Upgrading does not flash firmware or clear data. UI tests are not a full hardware regression; real SMTP, long/cross-carrier SMS and other Macs still require validation.

SMS/data may incur charges; acceptance is not delivery. Email forwarding defaults off and covers only newly synced messages after enabling; use trusted addresses. Secrets use Keychain and public artifacts contain no user data. Flashing overwrites original firmware without automatic backup; do not flash solely because a device is disconnected.
